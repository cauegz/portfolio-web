# Portfolio Web

Projeto de portfólio pessoal simples contendo páginas estáticas em HTML e CSS.

## Descrição

Site estático para apresentar projetos, habilidades e formas de contato.

## Tecnologias

- HTML
- CSS

## Estrutura do projeto

- `index.html` — página principal
- `css/style.css` — estilos
- `images/` — imagens do projeto
- `fonts/` — fontes usadas

## Como acessar a página 

- cole o seguinte link no navegador: `https://cauegz.github.io/portfolio-web/`
